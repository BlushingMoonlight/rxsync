# Segurança

Achou uma falha de segurança no site ou na plataforma da RXSync? Escreva para **contato@rxsync.com.br**, com o assunto
**"Segurança"**, dizendo o que encontrou e como reproduzir.

- Não abra Issue nem PR público sobre a falha.
- Não acesse, altere nem guarde dados de outras pessoas além do mínimo para mostrar o problema.
- Respondemos o recebimento assim que possível e avisamos quando a correção estiver no ar.

Para assuntos de privacidade e dados pessoais, use o mesmo endereço com o assunto "Privacidade" (ver a
[Política de Privacidade](https://rxsync.com.br/privacidade.html)).
